# OpenSource-lib

ארגז הכלים לאירוח עצמי: קטלוג בעברית של 1,545 כלי קוד פתוח מתוך שתי הרשימות awesome-sysadmin ו-awesome-selfhosted, ממופים ל-18 תחומים ולקשרים ביניהם.

לכל כלי: תיאור, פרטי אירוח עצמי, צילומי מסך, התחלה מהירה מתוך ה-README, קישורי תיעוד, רישיון, תאריכי יציאה ועדכון, תג Linux ותג Plug & Play. כולל דירוג לפי כוכבים ורשימת מעקב אישית.

## מקורות ורישוי

- [awesome-sysadmin](https://github.com/awesome-foss/awesome-sysadmin) ו-[awesome-sysadmin-data](https://github.com/awesome-foss/awesome-sysadmin-data), תחת CC BY-SA 4.0.
- [awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted) ו-[awesome-selfhosted-data](https://github.com/awesome-selfhosted/awesome-selfhosted-data), תחת CC BY-SA 3.0.
- צילומי המסך וקטעי הקוד לקוחים מקובצי ה-README של כל פרויקט ושייכים לבעליהם. כל אחד מהם מקושר למקור בדף הכלי.
- התיאורים והתרגומים לעברית נכתבו בעזרת בינה מלאכותית ועלולים לכלול אי-דיוקים.
